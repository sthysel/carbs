* noctalia

Noctalia is a Wayland desktop shell. This target uses it for the bar, the
notifications, the volume and brightness pop-ups, the wallpaper, the clipboard
history, and the lock screen. =rofi= stays the application launcher.

=binds.lua= has these keys for Noctalia:

| Key                  | Function          |
|----------------------+-------------------|
| Super + Ctrl + L     | Lock the screen   |
| Super + Shift + V    | Clipboard history |

** Clipboard

Noctalia reads the regular clipboard only. It does not read PRIMARY, so a client
that publishes selections often (Emacs with =select-active-regions=) does not
get a constant stream of read-backs. Do not add a clipboard daemon that watches
PRIMARY. This type of daemon can stop Emacs.

The history is encrypted on disk. The key is in the Secret Service.

** Configuration

- =config.toml= holds the settings for all machines.
- =machines/laptop.toml= and =machines/desktop.toml= hold the location and the
  clock format.
- =hooks/post.sh= links =~/.config/noctalia/machine.toml= to the file for the
  machine.

The Settings window writes to =~/.local/state/noctalia/settings.toml=, and this
file wins over =config.toml=. If a value in =config.toml= has no effect, look in
this file.

** Service

=noctalia.service= starts the shell with =graphical-session.target=. Noctalia
claims the notification name on D-Bus, so do not run another notification daemon
at the same time.

** Tray

The configuration hides the =nm-applet= and =blueman= icons, because the network
and bluetooth widgets show the same state. The applets keep running. =nm-applet=
answers the password requests for VPN and 802.1X connections.

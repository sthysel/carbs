#+TITLE: FreeCAD

[[https://www.freecad.org/][FreeCAD]] is a parametric 3D CAD modeller.

* Fonts

No configuration needed. FreeCAD 1.1 is Qt6, runs on the native Wayland
backend, and gets correct fractional scaling from the compositor -- on a 4K
panel at scale 1.5 the UI is legible as shipped. No desktop override, no
=QT_SCALE_FACTOR=, no font parameters.

** Do not force QT_QPA_PLATFORM=xcb

This target previously carried a hand-written desktop override pinning
=QT_QPA_PLATFORM=xcb=. That pin *was* the cause of unreadably small fonts:
=hyprland.lua= sets =xwayland.force_zero_scaling = true=, so anything pushed
onto XWayland renders at 1x regardless of the output scale.

Verified on FreeCAD 1.1.3 / Qt 6.11.1 that the pin is no longer needed --
=hyprctl clients= reports =xwayland: false=, a loaded model renders, and the
session emits no Qt warnings. If you hit a Wayland-specific bug and reach for
the xcb workaround again, pair it with =QT_SCALE_FACTOR= set to the output
scale, or you will get the tiny-font problem straight back.

** If it still looks small

=Edit -> Preferences -> General -> Interface= sets the UI font, and the model
tree carries its own size under =BaseApp/Preferences/TreeView/FontSize=. Change
those in the app rather than here: they live in =user.cfg=, which FreeCAD
rewrites wholesale on exit, so it cannot be managed from =config/=.
